# Overview

As a software engineer, I am working on improving my ability to build applications that store, manage, and retrieve data efficiently. This project helped me practice using a relational database with Python.

The Student Course Management System is a Python application that uses SQLite to manage student, course, and enrollment information. The program allows users to add, view, update, and delete student information, add and view courses, enroll students in courses, and view enrollment information.

I created this software to learn how Python applications can work with relational databases and how different tables can be connected using primary keys, foreign keys, and SQL JOIN operations.

[Software Demo Video](https://youtu.be/6NvIJKTGCaU?si=r2CabeSyXc9pX2cM)

# Development Environment

I developed this software using Visual Studio Code and used Git and GitHub to manage and publish the project.

The programming language used was Python. I used Python's built-in `sqlite3` module to create and interact with the SQLite relational database.
